# 20 Web Projects With Vanilla JavaScript

## 📚 Course

**20 Web Projects With Vanilla JavaScript**

[Udemy Course](https://www.udemy.com/course/web-projects-with-vanilla-javascript/)

## 📝 Course Overview

A project-based course focused on building practical web applications with vanilla JavaScript.

The course covers DOM manipulation, events, APIs, browser features, and interactive UI implementation through 20 projects.

## 🎯 Purpose

I am taking this course to:

- Build a solid foundation in JavaScript and apply my knowledge to practical projects
- Continuously learn new concepts and approaches through daily coding practice

## 🛠 Tech Used

- HTML
- CSS
- JavaScript (ES6+)
